# fydemo-landing

AITP（游戏本地化 AI 平台）营销落地页。单文件、纯前端、无后端依赖。

## 文件

- `index.html` — Vercel 默认部署入口
- `landing.html` — 源文件（内容与 index.html 相同）

两份文件内容一致，全部内联 CSS/JS，无外部资源引用，可直接双击打开或静态托管。

## 本地预览

```bash
python -m http.server 8899
# 访问 http://localhost:8899/
```

## 部署

已托管在 Vercel：https://fydemo.vercel.app
